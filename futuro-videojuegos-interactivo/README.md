# 🎮 El futuro de los videojuegos — Mundos que evolucionan

Una presentación interactiva, en un único archivo HTML, que explora hacia dónde van los videojuegos: mundos persistentes, personajes con IA, contenido generativo, nuevas interfaces y ecosistemas de agentes.

> Repositorio de ejemplo para una clase: muestra cómo se puede construir y publicar una experiencia web completa **sin frameworks, sin instalación y sin dependencias**.

## ✨ Qué incluye

- 9 capítulos navegables con transiciones suaves
- Vista general de capítulos (menú de miniaturas)
- Un **Laboratorio de futuros**: sliders y modos de juego que generan un concepto de videojuego en tiempo real
- Diseño responsive (escritorio y móvil)
- Respeta `prefers-reduced-motion`

## 🚀 Cómo usarlo

No necesitas instalar nada.

1. Descarga o clona este repositorio:
   ```bash
   git clone https://github.com/Fedgutcor/la-ultima-diapositiva-aburrida.git
   cd la-ultima-diapositiva-aburrida/futuro-videojuegos-interactivo
   ```
2. Abre `index.html` (dentro de esta carpeta) en tu navegador (doble clic).

## ⌨️ Controles

| Tecla | Acción |
|-------|--------|
| `←` / `→` | Navegar entre capítulos |
| `Espacio` | Siguiente capítulo |
| `O` | Abrir / cerrar la vista general |
| `F` | Pantalla completa |
| `Esc` | Cerrar la vista general |

## 🧠 Qué se puede aprender de este ejemplo

- Cómo estructurar una presentación con HTML semántico (`<section>`, `<header>`, `<main>`)
- Variables CSS (`:root`) para un sistema de diseño consistente
- Animaciones y transiciones solo con CSS
- Interactividad con JavaScript puro (teclado, botones, sliders)
- Diseño adaptable con *media queries*
