# La última diapositiva aburrida

Traducción al español de *The Last Boring Slide*: una presentación 3D sobre el futuro de la IA, contenida en **un solo archivo HTML** (`index.html`) que funciona sin conexión.

## Cómo usarla

1. Abre `index.html` en un Chrome, Edge, Safari o Firefox reciente, en un computador (requiere WebGL 2).
2. Navega con las flechas, la barra espaciadora o haciendo clic.

| Tecla | Acción |
|---|---|
| `→` / espacio / clic | Siguiente |
| `←` | Atrás |
| `F` | Pantalla completa |
| `A` | Reproducir solo |
| `M` | Sonido activado o silenciado |
| `N` | Notas del orador |
| `P` | Notas en una segunda ventana |
| `O` | Todas las diapositivas |
| `.` o `B` | Pantalla en negro |

Se puede abrir una diapositiva directamente con `index.html#aim` o `index.html#aim-2` (escena y número de paso). Con `?quick` se omite la pantalla de carga.

## Qué se tradujo

- Todos los textos de las diapositivas, las notas del orador y la interfaz (ayuda, avisos, carga).
- Las cifras usan formato colombiano (coma decimal, punto de miles).
- El título del documento y la fecha de la última diapositiva (ahora «25 de noviembre de 2026»).
- Las miniaturas del menú «Todas las diapositivas» y de la pared final se regeneraron a partir de la versión en español.

## Notas

- Los nombres de modelos y organizaciones (GPT-4, Opus 4.5, Mythos Preview, METR, AI Futures Project) se dejaron tal cual.
- El archivo incluye [three.js](https://threejs.org) (licencia MIT) y las tipografías incrustadas.
- Es una traducción no oficial del contenido original.
